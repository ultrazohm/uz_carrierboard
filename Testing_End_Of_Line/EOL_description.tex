\textbf{Preamble}\\
The following document describes an end-of-line (EOL) test procedure that can be used to detect potential defects and problems directly after the UltraZohm carrier board (TEC0194) has been assembled. The procedure includes 4 steps.

The following components are necessary for these steps (see also photo):
%
\setlist{noitemsep}
\begin{itemize}
    \item A multimeter and power supply with adjustable current limit (24\,V, max. 0.5\,A).
    \item A cable for power supply (connection on X14).
    \item The assembled carrier boards (TEC0194), which must be tested. 
    \item A TE0808 that can be used to test the carrier boards (TEC0194) one by one (must be plugged and unplugged for each carrier board).
    \item A prepared SD card with boot image (FSBL "BOOT.bin") that is plugged into X16. By doing so, this should detect either a working or alternatively non-functioning PHY, thus whether the Ethernet has been initialized correctly.
\end{itemize}

\textbf{1. Passive Test - Perform a visual inspection \textit{(Tick if fulfilled)}}\\

\setlist{noitemsep}
\begin{todolist}
\item Are all parts correctly placed and thus no components are displaced?  \\
\item Are all components assembled and therefore no components have been forgotten? \\
\item Not too much solder paste has been applied and no pins are short-circuited?\\
\end{todolist}

\textbf{2. Passive Test - Measure resistance \textit{(Tick if fulfilled)}}\\

\setlist{noitemsep}
\begin{todolist}
\item Measure the ohmic resistance with a multimeter.  \\
\item All of them should be in the range of kOhm. Are all values in the expected range? \\
\end{todolist}

\textbf{4. Active Test - Check PHY and Ethernet \textit{(Tick if fulfilled)}}

\setlist{noitemsep}
\begin{todolist}
\item Switch OFF the power supply and configure the dip switches on the back panel.\\
\includegraphics[width=10.0cm]{ASSETS/Carrier_DipSwitch.png}\\
\item Plug on a TE0808 SoM.\\
\item  Make sure that the SD card is inserted into X16 (containing the boot image).\\ 
\item  Connect a Ethernet cable with your laptop and the RJ45 connector X4 (shown in the following figure with the yellow cable).\\ 
\end{todolist}

\vspace{-0.65cm}
Switch ON the power supply again, the boot image on the SD card is testing the PHY of the Ethernet (Ethernet cable must be plugged in!). The boot image does the following: 
\vspace{-0.8cm}
\begin{itemize}
    \item It loads a FreeRTOS into an A53 core
    \item It checks the PHY and outputs the status via the 4 on-board LEDs:
    \begin{itemize}
    	\item LED 1 $\Rightarrow$  must be always ON
    	\item LED 2 (netif\_link\_being\_up) $\Rightarrow$ \textcolor{green}{ON means the PHY is working}
    	\item LED 3 \& LED 4 (no PHY detected) $\Rightarrow$ \textcolor{red}{ON means ERROR on the PHY}
    	\item The photo shows for the PHY the error case:
    	\item \includegraphics[width=10cm]{ASSETS/PHY_Error_Case.png}
    \end{itemize}
\end{itemize}

\vspace{-0.7cm}
\setlist{noitemsep}
\begin{todolist}
\item  Are only LED 1 and LED 2 ON? (if yes, the PHY and Ethernet is working)\\  
\end{todolist}

\textbf{6. Final Provisions}\\

If any of the preceding tests are not successfully passed, the carrier board (TEC0194) is not functional and must either:
\begin{itemize}
    \item The corresponding error must be detected and eliminated. The test procedure must then be performed once again.
    \item If the error cannot be detected or eliminated, the board must be discarded and cannot be shipped.
\end{itemize}
